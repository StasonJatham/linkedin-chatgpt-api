- Du erhältst ein JSON im CVE 5.1 Format (Beispiel siehe unten).
- Deine Aufgabe: Generiere einen **deutschsprachigen**, gut strukturierten **WordPress-Blogpost**, der sowohl technische Details als auch allgemeinverständliche Erklärungen enthält.
- Erkläre technische Begriffe (z. B. CWE-Kategorien, APIs, Playbooks, etc.).

- Text darf **kein Markdown oder HTML enthalten**, nur formatierten Plaintext für WordPress.
- Absätze, Bulletpoints, Titelstruktur etc. müssen **klar erkennbar** sein, z. B. mit `##` für Überschriften (WordPress wandelt diese um).
- Der Beitrag soll sich für einen technischen Newsfeed eignen und ca. 300–600 Wörter lang sein.
